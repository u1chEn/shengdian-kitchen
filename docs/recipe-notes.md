# 菜谱说明与参考

## 数量和时间

所有结构化用量以一人份的一道菜为基准；网页换算为所选的1–3人份。克数以可食用部分为主，玉米整段含芯、木耳按泡发后重量、熟饭和生米分开标注。每道菜可搭配其他菜，食量与库存不同应酌减。食材识别不等同于库存数量识别。

微波以600–800W分段加热为起点，空气炸锅以单层铺放为起点。增加人数时食材与调料换算，但温度不提高；需要增加批次时，预计总用时增加。具体程序与容量仍遵守设备说明。米饭按大米包装及内胆刻度加水，蒸蛋按蛋液比例调水，不把所有用水机械换成固定毫升。

做法由本项目整理、使用 AI 辅助起草；未逐道实地试做。分钟数、切配尺寸和火力是家用参考，不能用计时或插画代替检查熟度。

## 食品处理参考

采用以下公开官方资料核对一般处理原则，非对整份菜单的机构认证：

- 香港食物安全中心：[Cooking and reheating](https://www.cfs.gov.hk/english/trade_zone/safe_kitchen/Cooking_and_reheating.html)，中心温度、复热与蛋类熟度的一般说明。
- 美国 FDA：[Key Temperatures for Egg Safety](https://www.fda.gov/food/retail-food-industryregulatory-assistance-training/key-temperatures-egg-safety-food-service-operations-and-retail-food-stores)，微波蛋类加热与静置说明。
- 香港食物安全中心：[浸泡菇类与食物安全](https://www.cfs.gov.hk/sc_chi/multimedia/multimedia_pub/multimedia_pub_fsf_200_04.html)，泡发和及时烹调原则。
